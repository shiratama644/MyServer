# インフラ構成

## ハードウェア

- **マシン:** ミニPC
-   **CPU:** Intel Core i3（4コア、世代不明）
    -   cod-web で20〜50人の同時接続を想定
    -   4コアで全サービスを動かすため、CPU使用率を監視
    -   厳しい場合は game コンテナのみ VPS に分離する方針
- **RAM:** 16GB
- **ストレージ:** 1TB

## ホストOS

- **OS:** Proxmox VE
- **仮想化方式:** LXCコンテナ
- **ゲストOS:** Ubuntu（全コンテナ共通）

## ネットワーク

- **ドメイン:** `shiratama.mydns.jp`
- **リバースプロキシ:** Nginx（LXCコンテナ）
- **SSL:** Let's Encrypt (HTTPS対応)
- **ルーティング:** パスベース (`shiratama.mydns.jp/<site>`)

- **役割:** オンラインゲームの実行（app コンテナと分離してリソースを保護）

- **URLパス:** `/cod/`（Nginx経由でプロキシ）
- **構成:**
  - Bun (ランタイム)
  - Vite (ビルド)

## メモ・課題

- **Flashcard** は Next.js への移行がまだ。アカウント登録・課金システム (Stripe等) の導入予定あり。
- **ytdl** は ffmpeg が必要（動画ダウンロード・多重化用）。app コンテナにインストール必要。
- **cod-web** は Node.js ではなく **Bun** を使用。PM2 v7 で正式に Bun 対応済み（`pm2 start app.ts` で自動判別）。
- **PalmIDE** はクライアントサイド中心（IndexedDB + Gemini API 直接通信）。DB不要の可能性高い。
- **Dashboard** はこれから設計。サーバー監視、コンテナ管理、ログビューア等を想定。
